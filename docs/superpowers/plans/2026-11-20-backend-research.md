# Backend Research Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the two-sub-agent search loop with code-planned research (fixed tasks, cached, parallel Tavily calls) and one synthesis call, keeping every input and output of the legacy Streamlit app working.

**Architecture:** A structured brief is built from the legacy form. Code turns it into a fixed list of research tasks. Tasks run concurrently through a SQLite cache, using the async Tavily client. One plain model call writes the plan from the results. `run_plan` is the single entry point for the legacy app, the CLI, and the future frontend.

**Tech Stack:** Python 3.13, LangChain (`init_chat_model`, message classes), `tavily-python` 1.1.0 (`AsyncTavilyClient`), `python-dotenv`, Streamlit (existing UI), Python standard library (`asyncio`, `sqlite3`, `unittest`, `dataclasses`, `csv`).

**Spec:** [docs/superpowers/specs/2026-11-20-backend-research-design.md](../specs/2026-11-20-backend-research-design.md)

## Global Constraints

- Python 3.13 (`requires-python = ">=3.13"`); no new dependencies. Tests use `unittest`, not pytest.
- Default model `nvidia/nemotron-3-ultra-550b-a55b`, built through `create_chat_model()`.
- No sub-agent or multi-agent objects in the search path.
- Scope: 50 US states plus DC. Territories are excluded.
- Currency keeps the legacy selector (EUR, GBP, CAD, AUD, USD), for parity. The plan states that its prices are US-based figures.
- `COST_REFERENCE_YEAR = 2026`; cache TTL 1 day for availability tasks and 30 days for price tasks; `CONCURRENCY = 5`; `RETRIES = 1`; `MAX_RESULTS = 5`; `SEARCH_DEPTH = "basic"`.
- No runtime call to any location API. Location data comes from the Census snapshot in `data/`.
- Parity: every legacy form field and output (plan text, download, session saved runs) still works.
- No commit steps. Commit only when asked.

**Running tests (all tasks):** from the project root, `set PYTHONPATH=src` (PowerShell: `$env:PYTHONPATH="src"`), then `python -m unittest discover -s tests -t .`. Run one module with `python -m unittest tests.test_<name> -v`.

## Review Focus

1. **Location text outside the US or not matching a city in that state** → `BriefError` before any search. Owner: Task 2.
2. **Guest count outside 10 to 1000, or budget low above budget high** → `BriefError`. Owner: Task 2.
3. **A Tavily call fails after its retry** → the task is `failed`, the run continues, and its section reads "no data". **A missing `TAVILY_API_KEY`** → `ConfigurationError` before any search. Owner: Tasks 5 and 7.
4. **Cache file corrupt, unreadable or unwritable** → the run continues without the cache and logs a warning. Owner: Task 4.
5. **No research priorities selected** → zero searches, and the plan is still produced from the brief. Owner: Tasks 3 and 7.

### Task 4: Search cache

**Interfaces:**
- Produces:
  - `normalize_query(text: str) -> str`: lowercase, remove double quotes, collapse whitespace, strip.

  - `class SearchCache`: `__init__(self, path: Path | None)`; `get(self, key: str, now: float | None = None) -> dict | None`; `set(self, key: str, response: dict, ttl_seconds: int, now: float | None = None) -> None`; `close(self) -> None`.

- Failures: `sqlite3.Error` or `OSError` in `__init__` logs a warning and leaves the cache disabled (`get` returns `None`, `set` does nothing). Invalid JSON in a row returns `None`. Errors in `get` or `set` after startup are logged and treated as a miss or a no-op.

### Task 5: Search execution

**Files:**
- Create: `src/vows_n_knots/search.py`
- Test: `tests/test_search.py`

**Interfaces:**
- Consumes: `ResearchTask` (Task 3); `SearchCache`, `make_cache_key` (Task 4); config constants (Task 3).
- Produces:
  - `@dataclass(frozen=True) class TaskResult: task: ResearchTask; status: str; response: dict | None; error: str | None; seconds: float`. `status` is `"ok"`, `"cached"` or `"failed"`.
  - `async def run_tasks(tasks: Sequence[ResearchTask], client: Any, cache: SearchCache | None, location_id: str, *, concurrency: int = CONCURRENCY, retries: int = RETRIES, retry_delay: float = 1.0, on_event: Callable[[str, str], None] | None = None) -> list[TaskResult]`
- `client` is any object with `async search(query, search_depth, max_results, include_domains)`, matching `AsyncTavilyClient`. Pass `include_domains=list(task.include_domains) or None`.
- Search parameters for the cache key: `{"search_depth": SEARCH_DEPTH, "max_results": MAX_RESULTS, "include_domains": sorted(task.include_domains)}`.
- Cache TTL: `TTL_AVAILABILITY_SECONDS` or `TTL_PRICE_SECONDS`, from `task.cache_class`.
- Flow per task: check cache, then run under a semaphore of `concurrency`, call `client.search`, retry up to `retries` times on any exception (waiting `retry_delay` seconds), store the raw response, and return a `TaskResult`. Results come back in input order. `on_event` receives `("task_started", query)` and `("task_finished", status)`.

### Task 7: Plan runner

**Files:**
- Create: `src/vows_n_knots/run.py`
- Test: `tests/test_run.py`

**Interfaces:**
- Consumes: `StructuredBrief`, `brief_to_text` (Task 2); `build_research_tasks` (Task 3); `SearchCache` (Task 4); `run_tasks`, `TaskResult` (Task 5); `synthesize` (Task 6); `ConfigurationError` from `config/settings.py`; `create_chat_model` from `adapters/model.py`; `AsyncTavilyClient` from `tavily`.
- Produces:
  - `@dataclass(frozen=True) class ProgressEvent: kind: str; detail: str`
  - `@dataclass(frozen=True) class RunSummary: searches: int; cache_hits: int; failed_tasks: int; search_seconds: float; model_seconds: float; total_seconds: float`
  - `@dataclass(frozen=True) class Plan: text: str; section_status: dict[str, str]; summary: RunSummary`
  - `def run_plan(brief: StructuredBrief, *, on_progress: Callable[[ProgressEvent], None] | None = None, cache: SearchCache | None = None, search_client: Any | None = None, model: Any | None = None) -> Plan`

Behavior:
- Build the tasks. If there are tasks and `search_client` is None, check `os.getenv("TAVILY_API_KEY")` (after `load_env()`) and raise `ConfigurationError` if it is missing, before any search. Create `AsyncTavilyClient()` when no client was given.
- Create `model` with `create_chat_model()` when none was given. Only build it when the synthesis step runs.
- Run the tasks with `asyncio.run(run_tasks(tasks, client, cache, brief.city_id, on_event=...))`.
- Section status, one entry per selected research section: `"no data"` when every task in it failed, `"partial"` when some failed, otherwise `"ok"`. Each planner-only priority gets `"planner only"`.
- Synthesis: `synthesize(model, brief_to_text(brief), results)`.
- Summary: `searches` counts non-cached tasks that called the client, including retries. `cache_hits` counts cached tasks. `failed_tasks` counts failed tasks. Times are wall-clock seconds for the search phase, the model call, and the whole run.
- Emit `ProgressEvent`s: `"task_started"`, `"task_finished"`, `"synthesis_started"`, `"done"`. On any exception, emit `"failed"` with the message, then re-raise.
- Log the summary with the module logger from `config/logging_config.py`.
